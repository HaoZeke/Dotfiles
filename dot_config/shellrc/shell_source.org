* About
This file generates a shell startup script that is "pre-compiled" to be as fast as possible. This version uses extremely robust script blocks to avoid issues with Org Babel's output capture.

* Tangle-Time Computations
These blocks are the "compiler". They are executed by Org Babel but are not included in the final script. Their output is captured and inserted into the tangled file.

*** Calculate TeX Architecture String (Corrected)
This block has been rewritten to use variables and a single `echo` command at the end. This prevents Org Babel from incorrectly concatenating stdout from one command with the exit code of another.

#+name: calc-tex-arch
#+begin_src bash :results value :exports results
# Use variables for intermediate steps
ARCH=$(uname -m)
OS=$(uname -s | tr '[:upper:]' '[:lower:]')
# Produce the final output with a single, unambiguous command
echo -n "${ARCH}-${OS}"
#+end_src

*** Calculate Static PATH (Corrected)
This block has also been rewritten to be simpler and more explicit. It builds the result string in a variable and then `echo`es it at the very end. This is the safest possible approach.

#+name: calc-static-path
#+begin_src bash :results value :exports results
# A list of all static (non-conditional) paths we want to check.
declare -a static_paths=(
  "$HOME/.linuxbrew/bin"
  "$HOME/.poetry/bin"
  "$HOME/.local/bin"
  "$HOME/.yarn/bin"
  "$HOME/.go/bin"
  "$HOME/.emacs.d/bin"
  "$HOME/.cargo/bin"
  "$HOME/.local/bin/cronDrivers"
  "$HOME/.local/bin/cryptHelpers"
  "$HOME/.local/bin/dockerHelpers"
  "$HOME/.local/bin/droidHelpers"
  "$HOME/.local/bin/fileHelpers"
  "$HOME/.local/bin/gitHelpers"
  "$HOME/.local/bin/installHelpers"
  "$HOME/.local/bin/shellHelpers"
  "$HOME/.local/bin/webHelpers"
  "$HOME/perl5/bin"
)

declare -A seen
declare -a final_path_list=()

# Loop through paths and add only existing, unique ones to our final list
for dir in "${static_paths[@]}"; do
  if [[ -d "$dir" && -z "${seen[$dir]}" ]]; then
    final_path_list+=("$dir")
    seen["$dir"]=1
  fi
done

# Manually join the array into a colon-separated string.
# This is the most explicit and safe way to do it.
result_string=""
if [[ ${#final_path_list[@]} -gt 0 ]]; then
  # Build the string, element by element
  result_string="${final_path_list[0]}"
  for (( i=1; i<${#final_path_list[@]}; i++ )); do
    result_string+=":${final_path_list[i]}"
  done
fi

# Echo the final result as the very last action.
echo -n "$result_string"
#+end_src
