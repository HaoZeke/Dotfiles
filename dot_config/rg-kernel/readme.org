* Host policy

=linux-rg= is the custom kernel package for the ThinkPad X1 Carbon Gen 11
(=21HM002GUS=, host =rgx1gen11=). It is built as an Arch-native PKGBUILD with
=makepkg= and installed through the checked =linux-rg= reinstall helper, so
pacman owns the kernel package, the headers package is tracked, DKMS sees the
matching headers, and initramfs plus rEFInd checks run with the package install.

The package source of truth is the local =~/Git/Github/Tools/linux-rg= checkout,
which carries the adapted =0001= through =0021= patch queue, PKGBUILD, source
hashes, and host config. External kernels are not used as wholesale bases unless
they replace the base. CachyOS, Zen, Liquorix, CK, and Project C scheduler
material are tracked as patch and configuration sources in the linux-rg
manifests.

The stock Arch =linux= package is the required bootable fallback. =linux-lts=
is the recommended second rollback kernel because it does not follow the same
fast-moving series.

* Managed root helpers

linux-rg package helpers live in =~/Git/Github/Tools/linux-rg=. Host-local
policy wrappers live in chezmoi and are applied to =~/.local/bin=. The =/tmp=
scripts used during no-sudo runs are transport wrappers only; they should exec a
managed helper or be regenerated from one.

=rg-linux-rg-userspace-root-setup= is the privileged repair path for an
installed linux-rg tree. It syncs the current package helpers to =/usr/bin=,
refreshes the JSON-backed =rg-x1gen11-profile-root= helper in
=/usr/local/sbin=, refreshes installed =Module.symvers=, applies DKMS
compatibility overlays, rebuilds DKMS modules, enables the hibernate image-size
and oomd services, applies the daily laptop profile, rebuilds the linux-rg
initramfs, and runs the live kernel bundle.

=rg-linux-rg-postboot-check= is the privileged boot validation path after
selecting linux-rg in rEFInd. It validates the running kernel, required package
helpers, required exported symbols, DKMS modules, in-tree =v4l2loopback=,
boot/live contracts, scheduler/power userspace, active profile drift, sched_ext
mode drift, KSM madvise policy, and a thermal snapshot. It aggregates missing paths and failed
probes so one run shows every visible boot problem.

#+begin_src shell
sudo rg-linux-rg-userspace-root-setup 2>&1 | tee /tmp/rg-linux-rg-userspace-root-setup.out
sudo rg-linux-rg-postboot-check 2>&1 | tee /tmp/rg-linux-rg-postboot-check.out
#+end_src

=rg-kernel-build build= writes packages under
=~/.local/share/rg-kernel/artifacts/linux-rg=. The printed install command is
the privileged reinstall and boot-check step:

#+begin_src shell
sudo ~/Git/Github/Tools/linux-rg/scripts/rgx1gen11-reinstall-check-root --artifact-dir ~/.local/share/rg-kernel/artifacts/linux-rg
#+end_src

=rg-kernel-build refind-command= writes a rEFInd stanza to =/tmp= using the
current kernel command line with the initramfs changed to =linux-rg=.

* Design record
