* Laptop policy

The laptop keeps the stock Arch =linux= kernel as the required bootable
fallback. =linux-lts= is recommended as an extra rollback branch because it
does not track the same fast-moving kernel series, but the working stock
kernel is the install gate for custom artifacts. Custom work lands in one
experimental slot at a time through package artifacts built on =rg.cosmolab=.

The first laptop lane is =arch-zen=. It stays close to maintained Arch
packaging while giving an interactive desktop baseline. Kernel lanes are
renamed to =linux-rg-<lane>= package bases before =makepkg= runs, so installing
an artifact cannot replace =linux=, =linux-lts=, =linux-zen=, or CachyOS package
names. =rg.cosmolab= is Ubuntu, so native =makepkg= is optional: the launcher
uses an Arch =base-devel= container through Docker or Podman when the remote
does not provide Arch packaging tools. The remote build root lives on
=/scratch/goswami/rg-kernel-build= because the home directory is on the nearly
full root filesystem. =sched-ext= builds the =scx-scheds= scheduler tools and
keeps the stock kernel as a fallback-capable host for BPF schedulers.
=cachy-bore= is useful for performance comparison once the package lane is
stable. =ck-muqss= is kept as a revival lane because the public package state
is far behind the laptop's kernel series.

* Commands

#+begin_src shell
rg-kernel-build list
rg-kernel-build preflight
rg-kernel-build remote-preflight
rg-kernel-build prepare arch-zen
rg-kernel-build build arch-zen
rg-kernel-build build-all
rg-kernel-build install-command arch-zen
#+end_src

Kernel packages are installed manually with the printed =pacman -U= command
after the required fallback boot entry is present.
